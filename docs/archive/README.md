# Historical project artifacts

This folder contains material retained for audit/history but not required at the repository root for normal development, validation or deployment.

- `audits/`: 48 historical audit/review documents
- `releases/`: 28 historical release notes, deployment guides and checksums
- `verification/`: 104 historical validation/test outputs
- `manifests/`: 5 historical changed-file/manifests
- `migrations/`: 3 historical migration/auth notes
- `research/`: 1 retained research documents

The current release summary, current workspace audit, setup guides and deployment configuration remain at the project root. Generated `qa-v*/` browser artifacts were removed because the scripts in `scripts/` recreate them.
