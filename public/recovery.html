Pool Shed Data Recovery

This screen reads Pool Shed workspace copies stored in this browser. Nothing changes on the shared server unless an Admin deliberately chooses to publish a workspace as the shared master.

Your current browser workspace can now be promoted directly as the shared master. Before publishing, Pool Shed creates a local recovery copy, downloads a JSON backup, preserves the previous server revision, and protects permanent receipt / putaway history.

After the master is published, all authorised users load the same server workspace. Stale browser copies cannot silently overwrite a newer shared revision.
